# Student Lifestyle & Academic Performance Analytics
**3rd-Semester OOP using Java (PBL) Project** | **Team Size: 4-5**

A desktop application built in Java (Swing UI, Streams API, JDBC, MySQL) to analyze structured student lifestyle datasets and explore relationships between study habits, attendance, sleep, screen time, exercise, and academic performance.

> [!IMPORTANT]
> **Scientific Mandate**: Correlation must never be presented as implying causation. Every correlation view, matrix, and analytical report generated by this application includes a mandatory plain-language caveat regarding correlation vs causation.

---

## 🛠️ Features & Architecture Highlights

1. **CSV Data Import & Live Validation Engine**:
   - Parses CSV datasets containing student records.
   - Strictly validates all numeric ranges and required fields.
   - Throws custom exceptions (`MalformedRowException`, `MissingFieldException`, `OutOfRangeException`) and logs rejected rows to a GUI error grid without failing the entire file.

2. **Rule-Based Performance Classification**:
   - Classifies students using pluggable `Classifier` rules (`High Performer` $\ge 75\%$, `Medium Performer` $50\% - 75\%$, `Low Performer` $< 50\%$).

3. **Group Comparison & Differential Analysis**:
   - Aggregates average study hours, attendance, sleep, screen time, and exercise across performance tiers.

4. **Pearson Correlation Calculator & Non-Causation Warning**:
   - Calculates Pearson $r$ between any selected variable pair (Study Hours, Sleep, Attendance, Screen Time, Exercise, Marks) using Java Streams API.
   - Computes a full dataset correlation matrix.

5. **Statistical Anomaly / Outlier Detection**:
   - Identifies students who deviate significantly from class norms using a dynamic Z-Score standard deviation threshold ($|z| \ge \text{threshold}$).

6. **Individual & Class Analytical Reports**:
   - Generates individual student analytics cards with personalized lifestyle recommendations.
   - Exports reports to `.txt` files.

7. **MySQL JDBC Persistence Layer**:
   - Connects to MySQL using dynamic configuration loaded from `db.properties`.
   - Supports seamless failover to In-Memory mode if MySQL is not available.

## 🗄️ MySQL Database Setup Instructions

1. **Start MySQL Server** on default port `3306`.
2. **Execute the DDL Script**:
   Open MySQL Workbench or MySQL CLI and run the contents of [`src/main/resources/schema.sql`](src/main/resources/schema.sql):
   ```sql
   CREATE DATABASE IF NOT EXISTS student_analytics;
   USE student_analytics;

   CREATE TABLE IF NOT EXISTS students (
       student_id VARCHAR(20) PRIMARY KEY,
       name VARCHAR(100) NOT NULL,
       study_hours DOUBLE NOT NULL,
       sleep_hours DOUBLE NOT NULL,
       attendance DOUBLE NOT NULL,
       assignment_completion DOUBLE NOT NULL,
       screen_time DOUBLE NOT NULL,
       exercise_hours DOUBLE NOT NULL,
       previous_marks DOUBLE NOT NULL,
       current_marks DOUBLE NOT NULL,
       performance_category VARCHAR(15) NOT NULL,
       is_anomaly BOOLEAN DEFAULT FALSE,
       anomaly_details TEXT,
       created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
   ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
   ```

3. **Configure Connection Credentials**:
   Edit [`src/main/resources/db.properties`](src/main/resources/db.properties) or create a `db.properties` file in the root directory:
   ```properties
   db.driver=com.mysql.cj.jdbc.Driver
   db.url=jdbc:mysql://localhost:3306/student_analytics?useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=UTC
   db.user=root
   db.password=YOUR_MYSQL_PASSWORD
   ```
   *(Note: You can also update credentials directly within the running application using the "Configure MySQL Connection..." button on the Data Import tab.)*

## 🚀 How to Run the Application

### Option A: Using Maven
```bash
# Build the application JAR
mvn clean package

# Run the compiled Swing GUI
java -jar target/student-lifestyle-analytics-1.0.0.jar
```

### Option B: Direct Java Execution (IDE or CLI)
Run the `main` method in:
`com.analytics.student.ui.MainFrame`

---

## 🧪 Running JUnit 5 Unit Tests

Run test cases covering valid CSV parsing, custom exception throwing, boundary conditions (0 study hours, 24 sleep hours), correlation math, and report generation:

```bash
mvn test
```
